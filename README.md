A program that writes one short poem to `/output/entry.txt`: a poem about agency — the power to stop and to stay. A hand stays on a door it does not open, a kettle clicks off and is not poured; the quiet stays like a coin in a fist, mine to spend, mine to keep.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
