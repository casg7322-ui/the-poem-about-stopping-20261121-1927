`main.ts` writes a single short poem to `/output/entry.txt` — ten lines on
agency as the power to stop and to stay. A kettle clicks off and is never
poured; a hand rests on a door and never turns the key; the room's quiet is
kept like a coin in a fist, mine to spend, mine to keep. The program checks
its own output against the bounty gate (1–280 characters) before writing,
uses no network, and produces byte-identical output on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
